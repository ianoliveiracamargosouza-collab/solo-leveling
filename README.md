# Solo Leveling: Shadow Monarch

RPG 2D top-down em pixel art inspirado em Solo Leveling, construído a partir de uma cópia independente da base anterior.

## Direção do projeto
- Protagonista: Sung Jin-Woo.
- Progressão por nível, atributos, equipamentos, ouro e mana.
- Habilidades do Monarca no lugar das transformações.
- Portais e masmorras de rank E até S, além do Castelo do Monarca.
- Combate direto com movimentação 8 direções e controles para dispositivos móveis.
- Próximas etapas: extração de sombras, exército de sombras, invocação e comandos táticos.

## Desenvolvimento
Este repositório é independente de `dragon-ball-multiverse`. Alterações neste projeto não devem modificar o jogo Dragon Ball original.

O workflow Android está disponível em `.github/workflows/android-apk.yml`. A presença do workflow não significa que um APK já tenha sido compilado ou validado.
